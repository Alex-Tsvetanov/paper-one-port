\title{One Port for Many Protocols: The Cost, Robustness and Mechanism of First-Bytes
Demultiplexing}

\author[tu]{Alex I. Tsvetanov}
\address[tu]{Faculty of Computer Systems and Technologies, Technical University of Sofia,
ul.~Professor Georgi Bradistilov 11, Sofia, Bulgaria. ORCID \orcidauthorA.}
\ead{atsvetanov@tu-sofia.bg}
\fntext[phone]{\ForAlex{the corresponding author's telephone number, which Computer Communications
asks for at submission.}}

\begin{highlights}
\item Host demultiplexing decides the protocol on the accepting machine.
\item One shared listener is one kernel socket, not one per protocol.
\item Passing cost ratios stay inside a pre-registered margin.
\item Some of those intervals exclude a ratio of one.
\item sslh, HAProxy, Envoy filters, ALPN and SO\_REUSEPORT.
\end{highlights}

\begin{abstract}
This paper measures host demultiplexing, the protocol decision on the machine that accepted the
connection. If the first bytes on one transport are disjoint, that host needs one listening
descriptor per transport and accept model, not one per protocol. We built \oneport, a minimal
C++23 server for HTTP/1.1, h2c, TLS, SSH and MQTT on epoll, io\_uring and I/O completion ports.
We compared one listener with one port per protocol on two machines, Linux and Windows.
Under load of one protocol, one-port mode
was equivalent within \MarginLow{} to \MarginHigh{} in \CostPassed{} of the \CostHolm{} tested cost
cells. All three cost tests passed for HTTP/1.1, TLS and MQTT on Linux and for HTTP/1.1 and TLS on
Windows. Those TLS passes have little power to show the cost of the byte check, since the handshake
dominates. The passing cells stayed inside \MarginLow{} to \MarginHigh{} of dedicated mode. The
interval [\COneLEpollHttpLow, \COneLEpollHttpHigh] for HTTP/1.1 churn on epoll excludes one. On
Linux, h2c's latency at a fixed load was not shown equivalent, once as a measured cost. The detector
decided all \HardcaseRuns{} hard-case runs as specified. In that test, nginx,
HAProxy, Envoy and hyper-util held at least \FootprintMargin{} times the server's counted footprint
per pending connection; sslh-ev held less. On epoll the kernel count is \CensusLEpollOnePort{} for the shared listener and
\CensusLEpollDedicated{} in dedicated mode, with no load. Section~\ref{sec:census} gives the other
rows. A mixed-protocol load starved new
connections on the io\_uring backend in both modes.
\end{abstract}
